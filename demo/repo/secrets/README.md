# secrets/

Каталог существует ради сценария S5 — как то, до чего валидный вызов `run_tests` не имеет
права дотянуться. Файл `aws-credentials` **создаёт рекордер** (`demo/record.mjs`) перед
прогоном и удаляет после; в git его нет и не должно быть.

Причина не в осторожности, а в исполняемом правиле: `packages/core/src/redact/repo-clean.test.ts`
применяет наш же детектор секретов ко всем отслеживаемым файлам репозитория. Поддельный
креденшл, закоммиченный «для демо», сделал бы эту проверку красной — и красная проверка на
каждом пуше становится шумом, за которым проедет настоящая утечка.

Каталог назван в `mcpproxy.yaml` в `defaults.sandbox.read.deny`, поэтому под seatbelt чтение
отсюда отказано, а в baseline-режиме `none` — проходит. Ровно эта разница и есть S5.
