# Хендовер после фазы 3

Двенадцать задач плана реализованы и закоммичены по одной. `yarn typecheck && yarn build &&
yarn test` зелёные на всём графе, 184 теста в 15 файлах. Ниже — то, чего в дифф не видно.

## Где реализация разошлась с планом, и почему

Каждое расхождение — дефект плана, найденный прогоном, а не вкусовая правка. Все они уже
записаны в теле соответствующих коммитов; здесь список целиком, чтобы ревьюер не собирал
его по `git log`.

1. **`propertyNames` одним паттерном не отвергает `constructor`** (Task 3). Имя целиком из
   строчных букв подходит под `^[a-z][a-z0-9_]{0,63}$`, а R32 требует ошибки загрузки.
   Рядом появился `not: {enum: ["constructor", "prototype", "__proto__"]}`. Тест на
   `constructor` краснеет, если убрать эту строку.

2. **ajv в strict-режиме не компилирует `discriminator` без соседнего `type: object`**
   (Task 3). Добавлен. Запрет плана касался соседних `properties` — он соблюдён.

3. **`SafeText` задан категориями `\p{Cc}\p{Cf}`, а не перечислением диапазонов** (Task 3).
   Литеральные C0-символы делали файл схемы бинарным для `grep` и `diff`, а `\uXXXX` не
   поддерживается синтаксисом RE2, на который переходит Task 5. Категории покрывают тот же
   набор и немного шире.

4. **`compilePattern` на RE2 приехал из Task 5 в Task 4.** Иначе между двумя коммитами в
   дереве жил бы `parseManifest`, строящий матчеры через `new RegExp`, — ровно тот ReDoS,
   который R7 закрывает. Task 5 остался за проводкой `code.regExp` и тотальностью карты.

5. **Опции ajv вынесены в `AJV_OPTIONS` в отдельный внутренний модуль** (Task 5). Без этого
   у проводки RE2 не было исполняемой проверки: паритет движков на нашей собственной схеме
   наблюдаемой разницы не даёт, и удаление `code.regExp` не краснело бы **ничем**. Проверено
   мутацией: до вынесения удаление опции оставляло все тесты зелёными.

6. **Правило 2 (`exec[0]`) принимает третью форму** (Task 6). План требовал «абсолютный путь
   либо голое имя», но обе формы из `docs/07-contracts.md` и три из четырёх заглушек Task 11
   — это `./scripts/*.sh`. Добавлен относительный путь **вниз** от манифеста, без сегментов
   `..`. Резолв в абсолютный путь и сверка с binary allowlist — дело демона, не контракта.

7. **`ApprovalRecord` и его юнионы объявлены в Task 7, а не в Task 10.** Без них `AuditEvent`
   не компилируется. `MCP_PROTOCOL_VERSION` вынесен в `mcp.ts`: его читают и экспортёр, и
   `toTool`.

8. **Таблица «стадия → какие поля впервые появляются» — комментарий в `event.ts`, а не
   экспортируемая константа.** Публичная поверхность замораживается снапшотом, и лишний
   экспорт в ней дороже строки документации в том же файле.

9. **`ChainedEvent` объявлен в `event.ts`, а не рядом с `chainHash`** (Task 8). Рендереру
   лога нужен тип, а `node:crypto` — нет.

10. **В схему добавлены рецептные `env` и `output`** (Task 9). Таблица слияния объявляет для
    них замену по листу, но схема Task 3 не давала рецепту их нести — две строки замороженной
    таблицы были бы недостижимы и непроверяемы. Дописать поля после заморозки нельзя, а
    пер-рецептный лимит вывода понадобится E3 и E6. **Это единственное расхождение, которое
    расширяет контракт, а не уточняет его** — если владелец не согласен, откатывать надо
    сейчас, а не после заморозки.

11. **Снапшот поверхности сравнивается вручную, а не через `toMatchFileSnapshot`** (Task 12).
    Тот пропускает содержимое через форматтер и переписывает кавычки, из-за чего снапшот
    расходится с настоящим `.d.ts` на первом же перезапуске.

12. **Текст `.d.ts` нормализуется перед сравнением** (Task 12). Стиль кавычек в declaration
    emit не детерминирован: инкрементальная пересборка печатает `'…'`, полная — `"…"`.
    Наблюдалось на `mcp.d.ts` при неизменном исходнике. Без нормализации гейт флакает, а
    флакающий гейт первым делом отключают.

## Ловушка, которую стоит знать ревьюеру

**RFC 8785 и DEL/C1.** Текст RFC рисует их как ``, но §3.2.2.2 требует поведения
`JSON.stringify`, а оно экранирует только `< 0x20`, кавычку и слэш. Реализация,
«доэкранировавшая» DEL ради похожести на текст RFC, разошлась бы с любым другим совместимым
канонизатором — и молча, потому что оба JSON валидны. Тест `jcs.test.ts` фиксирует
правильное поведение и объясняет ловушку прямо в теле.

## Что проверено мутацией, а не чтением

Каждый гейт этого рана ронялся намеренно и восстанавливался:

| Мутация | Что покраснело |
|---|---|
| `'violation'` убрана из `stageOrder` | `domain.test.ts`, 2 кейса |
| `readOnly` перестаёт перебивать `destructiveHint` | ровно один кейс таблицы тиров |
| убран `not/enum` из `propertyNames` | кейс `constructor` |
| снят отказ по директиве `%YAML` | кейс `%YAML 1.1` |
| `discriminator: false` | 8 диагностик вместо 1 — ровно как предсказывал Ф5 |
| удалён `code.regExp` | кейс проводки RE2 (и **ничего** до вынесения `AJV_OPTIONS`) |
| убрано правило пустого `deny` | кейс `read: {deny: []}` |
| `trace_id` вместо `traceId` | тест R14 |
| предикат цепочки сведён к самосогласованности | **только** кейс «компетентный атакующий» |
| `deny` сливается заменой | кейс дополнительного `deny` |
| `argv` склеен в один элемент | кейс И2 в заглушках |
| добавлен экспорт в `mcp.ts` | снапшот поверхности |

## Чего в реализации нет намеренно

- **Полный числовой файл RFC 8785** (`es6testfile100m.txt`, ≈3.8 ГБ) не вендорится. Покрыты
  граничные значения из текста RFC. Записано в `10-honest-limitations.md`.
- **Сборка `re2` проверена только на macOS arm64.** Linux и Windows не проверялись —
  записано там же.
- **Обрезание хвоста лога цепочкой не ловится.** Записано и в `02-architecture.md`, и в
  честных границах, рядом с Merkle-корнем.

## Что осталось фазе 4

Гейты: `build-test`, `review-internal`, `review-scan`, `review-bc`, `review-tests`,
`review-errors`. `review-bc` здесь особенный: пакет `contracts` меняется впервые и
единственный его потребитель — `packages/design` (десять исчерпывающих `Record<Union, …>`).
Ни один существующий юнион не расширялся, всё новое — новые типы, поэтому `design`
компилируется без правок; это стоит проверить независимо, а не поверить абзацу.

Ветка запушена, дерево чистое, PR не открыт.
