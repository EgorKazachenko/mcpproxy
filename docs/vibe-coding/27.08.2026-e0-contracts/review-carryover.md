# Перенос из ревью: править по ходу реализации

Восемь MINOR раунда 7. Ни один не блокирует, и ни один не правился в `plan.md`:
одобрение гейта привязано к хэшу плана, и правка после вердикта его переоткрывает.
Каждый пункт — правка, которую делаем в момент, когда доходим до соответствующей задачи.

1. **Ф9 и строка R13 в таблице покрытия** всё ещё называют `jsonrpc.request.id`
   эмитируемым. Task 7 говорит обратное и явно объясняет почему. При реализации Task 7
   — не эмитить; при правке доков (Task 12) привести обе строки к списку из пяти
   атрибутов: `gen_ai.tool.name`, `network.transport` (константа `"pipe"`),
   `mcp.session.id`, `mcp.method.name`, `mcp.protocol.version`.
2. **`Tool` объявляется локально**, SDK в зависимости не попадает. Поля ревизии
   `2025-11-25`: `name`, `title?`, `description?`, `inputSchema`, `outputSchema?`,
   `annotations?`. Добавить `@modelcontextprotocol/sdk` в запретный список `deps.test.ts`.
3. **`gen_ai.operation.name`** имеет носитель (`operation`), но не назван в списке
   Task 7 — добавить в эмиссию.
4. **`ApprovalDecision = 'approved' | 'denied'`**; истечение и отмена выражаются
   отсутствием вердикта, а не третьим членом.
5. **Чистоту `.d.ts` проверяет снапшот Task 12**, а не `deps.test.ts` — либо
   переатрибутировать в Architecture, либо научить `deps.test.ts` смотреть и в `.d.ts`.
6. **`docs/07-contracts.md:120`** — вторая копия основания хэша рецепта, не внесена
   в таблицу сверки Task 12. Добавить строку: хэш по `normalized.own`, эффективный
   профиль лежит в `snapshot` ради диффа и не хэшируется.
7. **Остаточный расход на сборку `re2`** назначен Task 12, но в теле задачи не назван —
   дописать в правку `docs/10-honest-limitations.md`.
8. **Премисса P4** говорит «снимается в Task 11»; снятие `TODO(E0)` — Task 12.

Плюс не-находка, отмеченная ревьюером для реализатора: Task 7 обещает таблицу
«стадия → какие поля впервые появляются», а явно даёт четыре строки. Остальное
выводится из `stageOrder`, и все эти поля необязательны в любом случае, поэтому
ничего замороженного от точности этой таблицы не зависит.
