## Critical

**Дозапись после оборванного хвоста навсегда ломала журнал** (`internal` C1 · `scan` F1 ·
`bc` B4). Воспроизведено мной до правки:

```
после аварии:      {ok: true, count: 2}       ← R19 у читателя работал
после рестарта:    {ok: false, brokenAt: 2}   ← событие потеряно внутри порченой строки
следующий запуск:  бросает «повреждён»        ← демон больше не пишет аудит вообще
```

R17 сознательно отказывается от `fsync`, то есть оборванный хвост — **спроектированный** исход
падения демона. Читатель к нему готов, писатель не был: дескриптор на `'a'` приклеивал первую же
новую запись к огрызку. Второе последствие прямо запрещено `07-contracts.md` («отказ без записи
в аудит — баг»).

**Сделано.** Огрызок срезается при открытии по последнему `\n`, отсчёт в байтах (многобайтовый
`cwd` в последней записи иначе резался бы посередине символа). Факт починки отдаётся наружу
полем `repairedTornTail`. Семь тестов; мутация «убрать починку» красит пять.

## Minor и Nit — все закрыты правкой, кроме трёх записанных в границы

Исправлено: неиспользуемый импорт `unchain` (F7); протухшее исключение `api-surface.ts` в
списке покрытия (F8/T3); `MCPPROXY_HOME=''` → относительный путь журнала (F10); `PATH: ''` у
дочернего процесса (F11/нит); мёртвое присваивание `lastIndex` (F12); третья копия регулярки
специфаеров (F13, внутрипакетная половина); посторонний журнал, открытый посреди теста (F14);
сырой `ENOENT` из `exportJsonl` после уже созданного каталога (F16/EO4); структурные копии
контрактных типов вместо псевдонимов (m2); два хэндла на один файл (m4); потерянный отчёт при
`redact: false` (m5); список префиксов AWS не из названного набора — `AIDA`/`AROA` это
идентификаторы принципалов, а не креденшлы (m6); права уже существующего каталога (m8);
провенанс подстановки `PATH` (EO5); вакуумное утверждение о порядке ранов (T6); фикстура
границы, отстающая от константы (T7); `chain` в спане проверялся через поведение `toOtlp`, а
не через своё решение (T4); ветка часов по умолчанию не исполнялась ни одним тестом (T5).

**Записано в границы, а не исправлено** — с указанием, где именно:

- **F9** — потолок `maxBytes` применяется к каждому потоку отдельно, худший случай `2 × maxBytes`.
  Аргумент за (иначе длинный `stdout` съедает `stderr`, и при упавшей сборке модель получает
  гору логов без строки ошибки) сильнее аргумента против, но контракт несёт **одну** пару
  `output.{bytes,truncated}`, поэтому читать `bytes ≤ maxBytes` как инвариант нельзя.
  → `spec.md` «Что осознанно не сделано» + `10-honest-limitations.md`.
- **m7** — энтропия на входящем направлении выключена (R7/D3), поэтому секрет-параметр **без
  характерного формата** попадает в append-only журнал дословно и уезжает в экспорт. Включить
  её значит получать плейсхолдер вместо длинного пути или идентификатора сборки, то есть терять
  криминалистическую ценность записи ради редкой находки. → граница R9 в спеке +
  `10-honest-limitations.md`.
- **F13, межпакетная половина** — `api-surface.ts` в `core` почти дословно повторяет одноимённый
  модуль `contracts`. Вынести общий обходчик некуда: `contracts` заморожен в E0 и этот модуль
  наружу не отдаёт, а заводить devkit-воркспейс ради 40 строк дороже дублирования. Внутрипакетная
  копия убрана.

## Проверено мутациями, а не зелёным прогоном

Каждая правка ломалась обратно, прогон краснел, файл возвращался:

| Сломанная строка | Покраснело |
|---|---|
| починка оборванного хвоста убрана | 5 |
| версия сравнивается неравенством, а не порядком | 2 |
| проверка канонизируемости убрана | 3 |
| проверка прав каталога убрана | 1 |
| реестр открытых журналов убран | 2 |
| пересёкшийся кандидат снова выбрасывается целиком | 2 |
| сайдкар снова читает оригинал, а не копию | 1 |
| проверка владения свойством убрана | 1 |
| проверка типа значения убрана | 2 |
| отчёт снова выключается вместе с редакцией | 1 |

Две мутации сначала **не были пойманы** — сайдкар и `Object.hasOwn`. Обе означали слабый тест,
а не лишний код: у первого не было наблюдаемого окна между копией и чтением, у второго не было
случая с унаследованной **строкой** (проверка типа ловит только унаследованные функции). Оба
теста переструктурированы, после чего мутации краснеют.
