# Журнал мутаций — E2

Каждая строка: правило убрано из кода → какое утверждение покраснело. Прогон ручной,
результат записан здесь, потому что типовой трейс, который ничего не запрещает,
компилируется молча и выглядит как зелёный.

## Задача 1 — раннер

| Мутация | Результат |
|---|---|
| тестовый файл положен на уровень выше `src/` | `× раннер > не имеет тестов за пределами src/` — покраснело |

## Задача 2 — словарь отказов

| Мутация | Результат |

| `scrub` без `sanitizeDescription` (только зачистка суррогатов) | `× вырезает форматирующие символы` — покраснело; канонизация осталась зелёной |
| `scrub` без зачистки суррогатов (только `sanitizeDescription`) | `× канонизуется ВЕСЬ объект` — покраснело; проверка `Cf` осталась зелёной |

## Задача 3 — подготовка рецепта

| Мутация | Результат |
|---|---|
| убрана проверка слота в `exec` | `× каждый из четырёх нарушенных инвариантов` — вектор «слот в exec» |
| убрана проверка `root === "/"` | тот же `it`, вектор «root: "/"» |
| убрана проверка относительного `root` | тот же `it`, вектор «относительный root уходит за каталог» |
| убран счёт слотов в `argv` | тот же `it`, вектор «два слота в одном элементе» |
| убран гейт `isCanonicalizable` | 4 красных: exec[0], имя параметра, значение enum, имя рецепта |
| **уровня типа:** `matcher: PatternMatcher \| null` | СБОРКА: TS18047 ×2 + TS2322 на `_matcherNotNullable` |
| **уровня типа:** в ветку `string` добавлено `schema?` | СБОРКА: TS2322 на `_stringBranchClosed` + TS2578 на `@ts-expect-error` |
