# ADR-0003 — Схема событий совместима с OpenTelemetry GenAI

**Статус:** принято · 2026-08-27 · **Блокирует E0**

## Контекст

Нужна схема событий аудита. Соблазн — придумать свою, «под задачу».

## Решение

Событие аудита = надстройка над OTel GenAI semantic conventions.
Базовые поля их (`gen_ai.operation.name: execute_tool`, span kind INTERNAL, trace/span id),
наши — в namespace `mcpproxy.*`.

С v1.42.0 конвенции MCP переехали в тот же репозиторий OTel, то есть MCP-вызовы
описываются тем же словарём, что и агент, который их делает.

## Последствия

- ✅ Бесплатный экспорт в любой observability-стек
- ✅ Аргумент «встраивается в существующий контур», а не «ещё один формат логов»
- ✅ Готовый словарь атрибутов, не надо изобретать
- ⚠️ Статус `gen_ai.*` — «Development», не Stable. Форма спанов устоялась,
  но возможны правки. Приемлемо
- ❗ **Стоимость решения — ноль, если заложить в E0. Переделка потом — переписать
  семь зависимых эпиков.** Поэтому решение принимается до заморозки контракта
